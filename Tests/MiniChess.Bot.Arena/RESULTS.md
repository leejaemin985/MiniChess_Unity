# 봇 측정 기록

봇 경량화와 실력 조정 중 측정한 값을 시간순으로 남긴다. 다음 작업의 기준값으로 쓴다.

## 측정 방법

- **판단 시간**: `levelbench` 명령으로 잰다. 기기에서는 개발 빌드의 "Bot Bench" 패널로 잰다. 둘 다 시드 31의 같은 국면에서, 측정 봇(선공)과 레벨 6(후공)이 대전한다.
  - 결과는 레벨별 한 턴 평균 시간과 단계별 비용 비율이다.
  - 같은 국면이라 **노드 수가 같으면 판단도 같다**. 경량화가 판단을 바꾸지 않았는지 이 값으로 확인한다.
- **실력**: `match` 명령으로 잰다. 기본 100판이며, 같은 시드로 선후공을 바꿔 두 판씩 둔다. 결과는 A 기준 Elo와 95% 구간이다.
- **Unity 에디터 측정**: 코드 최적화를 Release로 두고, 별도 스레드에서 `BotBenchmark.Run`으로 잰다.

```
dotnet run -c Release --project Tests/MiniChess.Bot.Arena -- levelbench 7,8,9,10 --turns 3
dotnet run -c Release --project Tests/MiniChess.Bot.Arena -- match <봇A> <봇B> --games 100
```

## 판단과 보류

- **시간 상한**: 임시값 9999초로 사실상 제한이 없다. 경량화를 마친 뒤 기기 측정으로 정한다.
- **해시 개선**: 비중이 4~7%라 뒤로 미뤘다.
- **해시로 찾는 탐색 결과 캐시**: 해시 1회(65us)가 평가 1회(27us)보다 비싸서 하지 않는다.
- **판 복제와 행동 실행**: 합쳐서 약 58%다. Core 내부 동작이라 개선하려면 Core에 요청해야 한다.
